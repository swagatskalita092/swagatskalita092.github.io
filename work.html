FlashBuy

Flash-sale checkout backend

A checkout API for limited, contended inventory. The invariant: fixed stock is never oversold, no matter how many buyers hit it at once. Built with row-level locking (SELECT FOR UPDATE), idempotency keys, a Redis-backed waiting room with token-bucket admission, and Redis-lock leader election across replicas with an epoch fencing token (added after outside feedback caught a split-brain gap).

What actually broke, and what caught it

Commit a512729. A second bug (a post-commit false-failure race, e20d769) was found and fixed the same way. Chaos tests — killing the leader, Redis, and Postgres mid-sale by hand — found zero duplicate orders; killing Redis did lose in-memory waiting-room state (documented, not hidden).

Stack Overflow Survey Pipeline

Analytics pipeline over two real survey years

An Airflow + dbt + PostgreSQL pipeline over 154,000+ real Stack Overflow Developer Survey responses (2023 and 2024). The invariant: a bad or partial run can never become the published answer. Built on a candidate/publish pattern with a per-year monotonicity guard, required CI against hand-calculated fixtures, and a live, static dashboard regenerated from the real published data.

What actually broke, and what caught it

One of six hand-run failure injections against a real stack genuinely got through before this fix existed — the others (a killed loader, a killed database, a failed downstream test, two overlapping publishes) all held.

Fullproof Project Toolkit

Public methodology, skills & agent, v1.0.0, DOI-archived

The actual phase-by-phase method behind the three projects above, written down so anyone can follow it: pick an idea, name the risks, make provisional design decisions, build in verified phases, test adversarially, verify independently, and document honestly including the bugs. Nine docs, thirteen importable Claude skills, a seven-domain idea bank, and two full idea-through-resume worked examples. The umbrella methodology is also packaged as a standalone Claude Code agent that runs the whole pipeline autonomously on a project and hands back one verified report — including dispatching a genuinely separate agent for its own second-opinion and verification steps, rather than checking its own work.
